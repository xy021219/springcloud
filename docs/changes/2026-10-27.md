## 上传表格、改两列、再导出

- **改了什么**：新增 `backend/`（Spring Boot 4.1.2、内存 H2、`POST /api/sheets/preview` 和 `POST /api/sheets/export`）和 `frontend/`（Vue 3、Vite，一个页面）。新增 `.gitignore`。生产配置在 `backend/src/main/resources/application-prod.yml`，MySQL 只读环境变量，没有 `ddl-auto`。
- **为什么**：页面要能上传一份 `.xlsx`，只改两列文字，再下载。仓库里没有列名和改写公式，所以由用户勾选恰好两列。
- **影响面**：新页面和新接口。没有业务表，没有 DDL。
- **验证方式**：`mvn -q -DskipTests package` 退出码 0，生成 `backend/target/sheet-editor-0.1.0.jar`。`npm run build` 成功（Vite 7.3.7，10 个模块，436ms）。应用以默认配置启动，日志为 Spring Boot 4.1.2、Tomcat 8080、H2 `jdbc:h2:mem:sheeteditor`，本机没有启动 MySQL。预览接口返回「姓名、部门、备注」两行数据。导出接口 HTTP 200，文件 3423 字节，内容为「张三、平台、原备注1」和「李四、市场、原备注2」。5242881 字节的文件返回 HTTP 400，`文件超过 5 MB`。页面上勾选两列后第三列不可选，导出按钮从禁用变为可点，下载文件与上面的导出内容一致；同一页面选择 5242881 字节的文件后显示「文件超过 5 MB」。`git diff --stat` 为空，因为这些文件都还没被 git 跟踪。
